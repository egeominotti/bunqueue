# Changelog

The release history of bunqueue is maintained in a single file,
[`docs/src/content/docs/changelog.md`](docs/src/content/docs/changelog.md), and
published at [bunqueue.dev/changelog](https://bunqueue.dev/changelog/); every tagged
release also has notes on the
[GitHub releases page](https://github.com/egeominotti/bunqueue/releases). This file
only points there, so the history exists in one place. The official SDKs keep their own
changelogs in `sdk/<language>/CHANGELOG.md`.
