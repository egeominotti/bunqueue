# The known environment gap of the Bun-only OrbStack Machines.
#
# These unit tests run the version-gate step of .github/workflows/ci.yml under
# bash, and its first line is `node -p "require('./package.json').version"`. The
# Machines have Bun and no Node, so the step exits 127 with
# `node: command not found`. The sandbox image (oven/bun) and GitHub's
# ubuntu-latest both have a `node` on PATH, so the same tests pass there.
#
# One line per test: `test <file> <title>`, the title as bun prints it after
# "(fail) " (describe blocks joined with " > ", without the duration), under that
# file's header. scripts/machine-steps.sh reruns these files as they are and with
# a node->bun shim; scripts/machine-verdict.sh reports the gap (exit 3) only when
# the unit suite failed on exactly these file and title pairs and the shim rerun
# passed. test/agent-skills-machine-gate.test.ts checks that every title still
# exists in its file.
test test/repro-docker-version-gate-errors.test.ts an existing release permits Docker rebuild without a new GitHub release
test test/repro-docker-version-gate-errors.test.ts an absent tag permits the normal release path
test test/repro-release-source-commit.test.ts version gate resolves the exact release source commit > an existing lightweight tag is rebuilt from its tagged commit, not main
test test/repro-release-source-commit.test.ts version gate resolves the exact release source commit > an annotated tag is dereferenced to its commit instead of the tag object
test test/repro-release-source-commit.test.ts version gate resolves the exact release source commit > a tag whose commit carries another package version fails loudly
test test/repro-release-source-commit.test.ts version gate resolves the exact release source commit > a new version is released from the pushed commit
